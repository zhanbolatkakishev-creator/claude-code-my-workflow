# Replication Package — "Corridor, Not Factory"

**Paper:** Kakishev, Zhanbolat. "Corridor, Not Factory: Trade Reorientation and the Missing
Investment Response in Kazakhstan, 2022–2025."

**One-line summary:** A post-2022 trade reallocation raised Kazakhstan's re-exports to Russia
about tenfold in 29 product lines; the paper measures the shock, calibrates what Kazakhstan
retains (~a tenth of the domestic value added of a produced dollar), finds no investment
response across three deal databases, and reads the null through a three-gate framework.

This package regenerates every table, figure, and numeric claim in the manuscript from public
data plus one academically-licensed deal extract. It is R-only.

## 4. Computational requirements

See `output/computational_requirements.md` for the full block. In brief:

- **R 4.5.3** (2026-03-11), `x86_64`. R only — no Python, Stata, or MATLAB.
- **Key packages:** `fixest` 0.14.2, `strucchange` 1.6-0, `sandwich` 3.1-1, `data.table`
  1.18.6.1, `ggplot2` 4.0.2, `eurostat` 4.0.0, `jsonlite` 2.0.0, `readxl` 1.4.5, `wbstats`
  1.1. Full closure (78 packages) in `output/renv.lock` and `output/sessionInfo.txt`.
- **Restore the environment:** `R -e 'renv::restore()'` (or `install.packages()` of the
  `sessionInfo.txt` list). `FROM rocker/r-ver:4.5.3` reproduces a Linux layer.
- **Seeds:** `set.seed(20260831)` — `06_eventstudy_did.R` (bootstrap B = 1999, RI R = 2000)
  and `12_did_robustness.R` (permutation battery, produces Table 2 Panel C);
  `set.seed(1)` — `kz_valueadd/08_power_null.R` (MDE). `RNGkind()` = R default, no parallel
  streams.
- **Runtime:** approximately **12–18 minutes single-core**, analysis only (network fetches
  excluded): ~10–15 min for `kz_passthrough/00_run_all.R` — dominated by the wild-cluster
  bootstrap (B = 1999) and the two permutation batteries in steps `06` and `12` — plus ~2–3 min
  for `kz_valueadd/00_run_all.R`. The `fetch_*.sh` pulls and the live re-pulls in `04`, `07`,
  `11` add 15–30 min depending on the Comtrade/World Bank API. Peak RAM < 4 GB; no HPC or
  cluster required. *Author: replace with the measured wall-clock time from a clean run.*

## 5. Step-by-step run instructions

### 5.1 One-time setup

1. Restore the R environment: from the repo root, `R -e 'renv::restore()'`.
2. Set the Comtrade key: add `COMTRADE_PRIMARY=<your key>` to `~/.Renviron`.
3. Place the two pointer inputs:
   - OECD ICIO `2019_SML.csv` → `code/kz_passthrough/_data/icio/icio_ex/2019_SML.csv`
   - the licensed deal extract → `code/kz_valueadd/_data/20260825_Market size DA.xlsx`
     (see `data/raw/access-restricted-data.md` if you do not have it).

### 5.2 Fetch the raw trade data (network; ~15–30 min)

```bash
cd code/kz_passthrough
bash fetch_annual.sh          # keyless annual HS6
bash fetch_keyed.sh           # authenticated monthly HS6 (needs COMTRADE_PRIMARY)
bash fetch_neighbors.sh       # Armenia, Kyrgyz Rep., Georgia, Türkiye
cd ../kz_valueadd
bash fetch_kz_imports_hs2.sh  # HS2 imports for the sector-priority table
```

### 5.3 Run the analysis

```bash
cd code/kz_passthrough
Rscript 00_run_all.R          # trade shock, value capture, DiD, breaks -> _outputs/

cd ../kz_valueadd
Rscript 00_run_all.R          # investment response, sector priority -> _outputs/
                             #   (runs 01_read_deals .. 08_power_null; step 04 re-pulls
                             #    Comtrade HS2 and step 07 re-pulls World Bank WDI live)
```

Both pipelines use a `00_setup.R` that resolves all paths relative to the script directory;
`kz_valueadd` reads the trade-pipeline outputs from `../kz_passthrough/_outputs/`, so run
`kz_passthrough` first. Point `KZ_DEAL_XLSX` at the licensed extract if it is not at
`kz_valueadd/_data/20260825_Market size DA.xlsx`.

### 5.4 Expected outputs

Text results, `.rds`, and `.png` are written to `code/kz_passthrough/_outputs/` and
`code/kz_valueadd/_outputs/`. The manuscript reads the `.png` figures directly (via
`\graphicspath`) and transcribes numbers from the `.txt` files. `quality_reports/`
holds the reproducibility audit.

## 7. Populating the openICPSR tree from this repository

```bash
# from the repo root
mkdir -p replication_package/code replication_package/output

# code (exclude the ~620 MB raw-pull cache and the licensed xlsx)
rsync -a --exclude '_data/' --exclude '_outputs/' \
  scripts/R/kz_passthrough/ replication_package/code/kz_passthrough/
rsync -a --exclude '_data/' --exclude '_outputs/' \
  scripts/R/kz_valueadd/    replication_package/code/kz_valueadd/

# outputs (tables/figures/logs)
rsync -a scripts/R/kz_passthrough/_outputs/ replication_package/output/kz_passthrough/
rsync -a scripts/R/kz_valueadd/_outputs/    replication_package/output/kz_valueadd/
cp renv.lock replication_package/output/renv.lock
cp scripts/R/_outputs/computational_requirements.md replication_package/output/

# constructed analysis panels
mkdir -p replication_package/data/analysis
cp scripts/R/kz_passthrough/_outputs/panel_hs_period.rds \
   scripts/R/kz_passthrough/_outputs/surge_basket_stats.rds \
   scripts/R/kz_passthrough/_outputs/hs_class.csv \
   scripts/R/kz_valueadd/_outputs/deal_source_reconcile.csv \
   replication_package/data/analysis/
```
