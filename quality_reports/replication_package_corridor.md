## Skeleton built at

`replication_package/` — `README.md`, `DCAS_checklist.md`, `DEPOSIT.md` (openICPSR metadata
record), `data_editor_note.md` (cover note to the journal's Data Editor), `LICENSE.md`,
`data/raw/access-restricted-data.md`. The `code/` and `output/` directories
are **pointers** to the live `scripts/R/kz_passthrough/`, `scripts/R/kz_valueadd/`, and their
`_outputs/` — the README §7 gives the copy commands to populate the openICPSR tree (excluding
`_data/`, which is ~700 MB of raw pulls and is regenerated by the `fetch_*.sh` scripts).
